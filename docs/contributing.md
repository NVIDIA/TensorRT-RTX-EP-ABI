# Contributing

Thank you for your interest in the TensorRT RTX Execution Provider.

At this time, external contributions are not accepted. This project is
maintained internally by NVIDIA and is released as source-available under the
[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).

If you encounter a bug or have a feature request, please open an issue at
[github.com/NVIDIA/TensorRT-RTX-EP-ABI/issues](https://github.com/NVIDIA/TensorRT-RTX-EP-ABI/issues).

We may open the project to external contributions in the future. Please check
back for updates.
