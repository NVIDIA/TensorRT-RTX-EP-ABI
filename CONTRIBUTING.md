# Contributing to TensorRT RTX Execution Provider

Thank you for your interest in the TensorRT RTX Execution Provider.

At this time, **external contributions are not accepted**. This project is maintained internally by NVIDIA and is released as source-available under the [Apache License 2.0](LICENSE).

If you encounter a bug or have a feature request, please open an issue at
[https://github.com/NVIDIA/TensorRT-RTX-EP/issues](https://github.com/NVIDIA/TensorRT-RTX-EP/issues).

We may open the project to external contributions in the future. Please check back for updates.
